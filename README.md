# [모두의 진학] 그들이 좋아하는 탐구 검색기

학생부종합전형 면접에서 실제로 질문받은 탐구 1,510건(70개 대학)을 대학 · 학과 · 과목 · 단어로 찾아보고,
고른 카드만 PDF로 출력해 학생 상담 자료로 쓸 수 있는 정적 웹페이지입니다.

주소: https://park-sanggeun-all.github.io/tamgu-search/

## 파일 (모두 저장소 최상단에 올리세요)
- `index.html` — 검색기 본체(데이터·로고 포함)
- `og-image.png` — 링크 공유 시 보이는 썸네일(1200×630)
- `favicon.png`, `apple-touch-icon.png` — 브라우저 탭·홈 화면 아이콘

## GitHub Pages 설정
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save

## 썸네일이 안 바뀔 때
카카오톡·페이스북은 썸네일을 저장해 두기 때문에, 처음 공유한 뒤 이미지를 바꿨다면 캐시를 지워야 합니다.
- 카카오톡: https://developers.kakao.com/tool/debugger/sharing 에서 주소 입력 후 “캐시 초기화”
- 페이스북: https://developers.facebook.com/tools/debug/ 에서 “다시 스크랩”
